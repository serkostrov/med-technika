# Краткая инструкция пользователя

Система учёта протоколов ИЛ ООО «Медицинская Техника» и подготовки XML для ФГИС.

## Роли

- **Инженер** — свои протоколы: загрузка, правка сопоставлений, скан, принятие замечаний.
- **Начальник ИЛ** — все протоколы, утверждение/возврат, выгрузка XML, справочники, пользователи и настройки.

## Типовой сценарий

1. **Загрузка** — перетащите Excel. Система определит форму, разберёт шапку и результаты. Сохраните протокол (статус «На проверке»).
2. **Карточка** — вкладки «Сводка», «Результаты», «Оборудование», «Проверка». Исправьте сопоставления (заказчик, СИ, ОА), если нужно.
3. **Проверка** — устраните ошибки (E…). Замечания (W…) примите к сведению (комментарий необязателен).
4. **Утверждение** (начальник) — кнопка «Утвердить».
5. **Скан** — прикрепите PDF. Укажите дату заявки. Статус станет «Готово к передаче».
6. **Выгрузка** — выберите до 100 протоколов ready (или exported для повтора) → «Сформировать XML» → скачайте → отметьте загруженным во ФГИС.

## Реестр

Фильтры: номер, заказчик, объект, заводской №, вид, исполнитель, период, статус.  
Быстрые: не передано во ФГИС / с ошибками / без скана / без даты заявки.

## Важно

- Измерения из Excel **нельзя** править в системе — только новый файл (replace).
- Отправка во ФГИС через API **не входит** в систему — только файл XML и ручная отметка.
- Формы без материалов клиента недоступны для разбора.

## Журнал

Все действия пишутся на сервере автоматически (кто / когда / объект / действие / diff).
